# 新建项目

`project create --category 分类 --name P001-名称 --id P001` 与 `init 目标路径 --kind project --parent 主库路径 --id P001` 共用生成引擎。
目标必须在主库科研项目目录内，不得位于其他项目中；项目编号和注册名必须唯一。
先加 `--dry-run` 查看文件与配置来源。已有内容拒绝覆盖，失败不留下有效半成品。
项目默认继承主库基础偏好与选中插件的程序，不继承插件 data.json、凭据和运行时索引。
未配置同步仍可离线创建；配置后在主库执行 `sync apply`。
详见 [[项目文件夹模板说明]]。
