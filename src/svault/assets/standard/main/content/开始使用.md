# 开始使用

在 Obsidian 中把本文件夹打开为 Vault，进入 [[科研工作台]]。
默认生成的是标准结构，不包含研究数据、示例项目或个人插件设置。
用 `工具/svault.exe project create --category 医学影像 --name P001-项目名称 --id P001` 创建真实项目；项目文件夹单独打开为 Vault。
主库管理总览与共享知识，日常工作进入子库。文献与实验笔记采用项目编号前缀，未知结果标记待核实。
当前仅提供 Windows exe，Vault 内不保留 Python 脚本。
